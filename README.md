# 이거먼저 🥬

> 냉장고 속, 오늘 먼저 챙길 재료

냉장고 속 식재료를 **위치와 시간** 기준으로 보여주고, 마감 임박 식재료가 버려지기 전에 **'오늘 할 행동 하나'**를 제안하는 개인 냉장고 관리 서비스입니다. 서비스 기획부터 구현까지 전 과정을 연습하는 미니 프로젝트로, 기획안 → 와이어프레임 → 웹 데모 순서로 만들었습니다.

**▶ 라이브 데모: https://stkd9w57jm-oss.github.io/igeomeonjeo/**

UI 테마는 **'프레시 팝(비타민)'** — [awwwards](https://www.awwwards.com/) 및 2026 푸드 앱 디자인 트렌드 리서치("에너지·대비의 복귀", 라임그린+쿨화이트, 시트러스 옐로)를 반영했습니다. 쿨 화이트 바탕에 라임그린을 하이라이터처럼 쓰고, 시트러스 옐로(마감할인)·코랄(임박)로 상태를 구분합니다. 굵은 Pretendard 산세리프, 부드러운 섀도, 경쾌한 마이크로 인터랙션이 특징입니다.

## 데모 실행

빌드·설치 없이 정적 서버로 열면 됩니다.

```bash
python -m http.server 8123
# → http://localhost:8123
```

데이터는 브라우저 localStorage에만 저장됩니다(서버 전송 없음). 첫 실행 시 샘플 식재료가 들어 있고, 설정에서 비우거나 다시 넣을 수 있습니다.

## 핵심 설계 원칙

1. **3초 등록** — 필수 입력은 이름·칸 두 개. 구매일은 자동(오늘), 보관기간은 품목 사전에서 자동 적용. 소비기한 입력은 접힌 선택 항목.
2. **하루 1회 확인** — 홈에는 '오늘 먼저 챙길 재료' 최대 3장만. 전체 재고 관리를 강요하지 않는다.
3. **알림이 아니라 행동 제안** — D-day 경고 대신 `오늘 먹기 · 냉동하기 · 손질하기` 선택지. 권장 기간 초과 시에만 '버리기 전 상태 확인'이 등장.

## 구현 범위 (기획안 "이번 웹앱 구현 범위")

- 냉장고 지도(냉동·냉장·문칸·야채칸)와 위치별 식재료 확인
- 구매일 + 권장 보관기간 기본값 기반 남은 기간 계산
- 마감 임박 식재료 우선 표시와 처리 행동 제안
- 식재료 추가 · 일부 사용 · 소비 완료 · 냉동 · 폐기(사유 기록)
- 전자영수증 텍스트 붙여넣기 일괄 등록 (실온·비식재료 자동 제외)
- 처리 기록 통계(소비/냉동/폐기, 폐기 전 처리율)

'알뜰' 탭은 P2(제휴 연동) 자리만 잡아둔 안내 화면입니다.

## 데이터 출처에 대한 주의

품목별 보관기간 기본값(`app.js`의 `FOOD_DB`)은 식약처 [식품유형별 소비기한 참고치](https://www.mfds.go.kr/brd/m_211/view.do?seq=14678)와 통용 보관 권장값을 **데모용으로 근사한 값**입니다. 실서비스에서는 참고치 원본 데이터로 교체해야 하며, 식품 안전 판단은 날짜보다 실물 상태 확인이 우선입니다.
