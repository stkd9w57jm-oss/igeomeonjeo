S6 · 상태 시트

재료 상태 변경

확인 루프의 종점 — 처리 기록

어느 화면에서든 재료를 탭하면 열리는 바텀 시트. 상태 모델(보유 → 일부 사용 → 완료·냉동·폐기)이 버튼 그대로다.

  • 1'일부 사용'은 수량 입력 없는 단일 버튼. 누르면 사용 이력만 갱신되고 항목은 유지된다 — MVP 상태 모델 그대로.
  • 2행동 제안 문구는 재료 특성(냉동 가능 여부)에 따라 달라진다. 광고·제휴와 분리된 영역.
  • 3폐기도 떳떳한 버튼으로 둔다. 폐기 사유가 쌓여야 성공 지표(폐기 전 처리 비율)와 개선 근거가 된다.
